Questions fréquentes

Vous ne trouvez pas votre réponse ? Écrivez-nous sur WhatsApp.

Faut-il Internet pour utiliser TRA-MANAGER ?

Non. Tout fonctionne sans Internet : ventes, stock, crédits, reçus. Internet sert seulement si vous activez la sauvegarde en ligne, ou pour payer votre licence.

Où sont enregistrées mes données ?

Sur votre téléphone ou votre ordinateur. Si vous activez la sauvegarde en ligne, une copie protégée est gardée sur Internet. Elle vous permet de retrouver vos données si vous perdez votre téléphone, et de travailler sur le téléphone et l'ordinateur avec le même compte. Voir la politique de confidentialité.

Où trouver le code de mon appareil ?

Dans l'application, ouvrez la page Licence. Le code ressemble à TM-XXXX-XXXX-XXXX. Chaque appareil a son propre code, et la clé achetée ne marche que sur cet appareil.

J'ai payé mais je n'ai pas reçu ma clé.

Restez sur la page après avoir validé le paiement sur votre téléphone : la clé s'affiche en général en moins d'une minute. Sinon, envoyez-nous sur WhatsApp le numéro qui a payé et le code de votre appareil, et nous vous envoyons la clé.

Comment renouveler ma licence ?

Achetez une nouvelle formule avec le même code d'appareil. Si votre licence est encore valable, collez votre clé actuelle sur la page d'achat : la nouvelle période commence à la fin de l'ancienne, vous ne perdez aucun jour.

Je change de téléphone, je perds mes données ?

Non, si vous avez activé la sauvegarde en ligne : installez TRA-MANAGER sur le nouveau téléphone et touchez « Récupérer mes données depuis Internet ». Pour la licence, contactez-nous avec l'ancien et le nouveau code.
